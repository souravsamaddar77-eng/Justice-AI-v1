# Justice AI brand assets

The current SVG mark adapts the app's navy-and-gold scales identity for use at
small sizes. The 32 px favicon and 180 px Apple touch icon are rendered from it.
The matching mark and wordmark were imported into an editable Canva design:
[Justice AI — Primary Logo](https://www.canva.com/design/DAHVXPYprEw/edit).
`justice-ai-logo-source.html` is the self-contained source for that design.

The site uses the original vector artwork and its PNG derivatives, not a
thumbnail or a time-limited Canva export URL. After future Canva edits, replace
justice-ai-mark.svg and regenerate the PNG sizes. The Navbar image and Next.js
metadata reference these stable asset paths. Keep the mark legible on both
themes and preserve its square viewBox.
