Retrieved 2026-09-13. Fonts are embedded and subset in server-generated case PDFs.
No font service receives case content. Devanagari supports Hindi and Marathi;
Bengali-script text is supported. Unsupported glyphs cause a clear export error
with the printable HTML option, rather than silently producing missing glyphs.
