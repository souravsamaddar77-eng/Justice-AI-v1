# Justice AI interface and reliability updates

## Implemented

- Home and global language selectors: English, Hindi, Bengali, Tamil, Telugu,
  Marathi, Gujarati, Kannada, Malayalam and Punjabi. Shared navigation, home,
  tool catalog, chat and main tool controls use translation catalogs. Specialist
  reference data and uncatalogued copy retain English; original documents and
  quoted source text are not translated automatically.
- Light, Dark and Auto-detect preferences persist locally, synchronize across
  tabs and track system changes. A before-paint script prevents a theme flash.
- A shared chat session connects the floating widget on every route with the
  full conversation page. Navigation retains input/history; account changes
  clear private conversation state. Chat history is not written to localStorage.
- Multilingual voice recognition and speech synthesis use the selected language.
  Only an unedited voice submission automatically reads its completed answer.
  Typed input, suggestion chips, canceled requests and stale replies stay silent.
  Device/browser speech support and installed voices still determine availability.
- Twelve contextual FAQ suggestions per language, clean plain-text AI output,
  and removal of processing-preference controls and request flags.
- Gemini followed by Groq for chat, drafts and analysis. Timeouts, provider
  outages and invalid structured output can fall back; user cancellation and
  safety refusals do not. Streaming clears incomplete provider text before
  displaying the replacement. Provider changes are not surfaced as UI steps.
- Standalone drafts print through a safely escaped browser view to preserve
  Indian scripts when saving as PDF. Some scripts use the device's fonts.
- Private storage configuration validation, useful setup errors, and corrected
  orphan cleanup using Supabase's bucket DELETE endpoint with `prefixes`.
  See [storage setup and RLS checks](storage-troubleshooting.md).
- A vector Justice AI mark, PNG favicon and Apple touch icon are integrated
  in the header and Next.js metadata. Matching artwork and wordmark are available
  as an [editable Canva design](https://www.canva.com/design/DAHVXPYprEw/edit),
  imported from the saved HTML design source. See [asset details](../public/brand/README.md).

## Verification

- 101 automated tests pass, including provider failures and interrupted streams,
  voice-origin policy, translations, preference persistence, multilingual print
  escaping, authenticated uploads and orphan cleanup.
- TypeScript validation and the production build pass.
- Real Groq requests passed through the actual chat, drafting and analysis route
  handlers after process-local simulated Gemini failures. Hindi streaming chat
  cleared partial output correctly; Bengali analysis retained the exact source
  deadline. No project environment values were changed by the probe.
- Browser checks cover desktop/mobile language switching, saved preferences,
  explicit light/dark appearance, live system-theme changes, chat input and
  completed-answer continuity, keyboard focus restoration and responsive layout.
  A real browser chat request returned readable text without automatic speech
  for the typed prompt. All 16 page routes pass the smoke check.
- Actual microphone capture and audible speech require device interaction and
  were not asserted from automated voice-policy tests.
